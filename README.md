# WireGuard Bot — постоянное меню

Файлы:
- `bot/keyboards.py`
- `bot/handlers.py`

Что изменено:
- добавлено постоянное ReplyKeyboard-меню Telegram;
- обычному пользователю доступна кнопка `📱 WireGuard`;
- администратору доступны `👤 Пользователь` и `🔐 Администрирование`;
- администратор может пользоваться пользовательским режимом и получать свои QR/конфигурации;
- после подтверждения регистрации пользователю автоматически выдаётся постоянное меню;
- `/start` и `/admin` оставлены как резервные команды;
- отправка заявки выполняется на `app.settings.admin_ids`, с логированием ошибки доставки.

База данных и WireGuard/RouterOS код не изменялись.

Перед заменой файлов рекомендуется сделать backup каталога `bot/`.
